# SQL Basics

Apuntes y ejercicios de aprendizaje de SQL. El repositorio reúne consultas prácticas, documentación y pequeños retos de bases de datos relacionales.

## Contenido

- `#APUNTES_SQL.md`: apuntes y referencia de sintaxis.
- `LaSQL 1.sql` a `LaSQL 8.sql`: ejercicios de la serie Lost at SQL.
- Consultas de práctica sobre selección, filtros y ordenación.
- Ejercicios de SQL Police Department.
- `SQLOps1.md` y `SQLOps2.md`: notas y prácticas adicionales.

## Temas

- SELECT, WHERE y ORDER BY.
- DISTINCT y operadores lógicos.
- Funciones de agregación.
- GROUP BY y HAVING.
- Consultas y análisis de conjuntos de datos.

## Ejecución

Las consultas deben ejecutarse sobre el esquema correspondiente a cada ejercicio en un SGBD compatible. No todos los scripts son autónomos ni comparten necesariamente el mismo modelo de datos.

## Tecnologías

- SQL
- Bases de datos relacionales
